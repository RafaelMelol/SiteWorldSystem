# Site World System

Site institucional da World System – Soluções em TI, de Lagoa da Prata/MG. A empresa desenvolve sistemas de gestão, PDV e emissão fiscal para pequenas indústrias, atacados e varejos desde 1993.

## Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- Motion
- Zod
- Resend
